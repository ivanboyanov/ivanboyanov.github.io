# VerbFit Deutsch

Готово адаптивно приложение за упражняване на спрежението на немски глаголи чрез флашкарти. Самият сайт е статичен и може да бъде публикуван безплатно в GitHub Pages. Firebase Authentication и Cloud Firestore се използват само за акаунтите, синхронизирането на прогреса, личните списъци и администраторските данни.

## Какво съдържа

- 331 основни и префигирани глагола;
- категориите **Regelmäßig**, **e → i**, **e → ie**, **a → ä**, **Ganz unregelmäßig**, **Modalverben** и **Andere Änderungen**;
- девет отделни варианта на местоименията при шест форми в парадигмата: `ich`, `du`, `er`, `sie – Singular`, `es`, `wir`, `ihr`, `sie – Plural`, `Sie`;
- претеглено повторение: ✕ увеличава вероятността отново да се появи конкретната комбинация „глагол + местоимение“, а ✓ я намалява;
- серия с огънче: денят се зачита след 15 оценени карти;
- немско озвучаване чрез вградения в браузъра Web Speech API;
- гост режим без запазване;
- регистрация само с потребителско име и парола — без истински имейл;
- до три лични списъка без ограничение на броя избрани глаголи;
- администраторски панел за нови глаголи и публични списъци;
- дизайн за телефон и компютър без компилиране и без framework.

## 1. Firebase проектът е настроен

Приложението вече е свързано с Firebase проекта `verbfit---deutsch`. Готовата конфигурация е записана в `js/firebase-config.js`.

Firebase конфигурацията на уеб приложението се вижда от браузъра по дизайн. Сигурността на данните се осигурява от Authentication и правилата в `firestore.rules`, а не чрез скриване на този обект.

## 2. Активирай входа с парола

**Статус:** Email/Password входът вече е активиран за проекта.

Във Firebase:

1. отвори **Authentication → Sign-in method**;
2. активирай **Email/Password**.

Потребителят на сайта вижда само полета **Benutzername** и **Passwort**. Приложението нормализира потребителското име и създава от него SHA-256 идентификатор, който използва като вътрешен технически адрес под домейна `users.verbfit.invalid`. Истински имейл не се иска и не се пази.

### Важно за забравена парола

Тъй като няма истински имейл, автоматичното „Passwort vergessen“ не е възможно. Забравена парола трябва да бъде сменена или акаунтът да бъде управляван ръчно през Firebase Console.

## 3. Създай Firestore и постави правилата

**Статус:** Firestore базата е създадена в регион `eur3`, а правилата от `firestore.rules` са публикувани.

1. Отвори **Firestore Database** и създай база.
2. Избери европейски регион.
3. Отвори раздела **Rules**.
4. Копирай целия текст от файла `firestore.rules`.
5. Натисни **Publish**.

Не оставяй базата постоянно в отворен Test mode.

Правилата правят следното:

- всеки потребител може да чете и променя единствено собствения си профил;
- личните списъци остават невидими за другите;
- публичните глаголи и списъци се четат и от гости;
- само UID, записан като активен администратор, може да добавя и изтрива публично съдържание;
- в профила не могат да бъдат записани повече от три лични списъка.

## 4. Дай си администраторски права

Името **Ivan Boyanov** е запазено като показвано име на администраторския панел, но само името не се използва за удостоверяване. Това би било несигурно, защото всеки може да го въведе. Ролята се свързва еднократно с твоя Firebase UID.

1. Публикувай сайта или го отвори през локален сървър.
2. Регистрирай се в приложението с потребителско име **Ivan Boyanov** и избрана от теб парола.
3. Отвори **Firebase → Authentication → Users**.
4. Копирай стойността **User UID** на своя акаунт.
5. Отвори **Firestore Database → Data**.
6. Създай collection с име `admins`.
7. В нея създай документ, чийто Document ID е точно копираният UID.
8. Добави поле:
   - име: `active`
   - тип: `boolean`
   - стойност: `true`
9. Излез и влез отново в VerbFit. В профила ще се появи **Adminbereich**.

Паролата ти никога не трябва да присъства във файловете, GitHub repository-то или Firestore правилата.

## 5. Публикувай в GitHub Pages

1. Създай ново GitHub repository, например `verbfit-deutsch`.
2. Качи **съдържанието** на тази папка в основната директория на repository-то. `index.html` трябва да е директно в root.
3. Отвори **Settings → Pages**.
4. При **Build and deployment** избери `Deploy from a branch`.
5. Избери branch `main` и папка `/(root)`.
6. Запази настройката.

## 6. Разреши GitHub домейна във Firebase

След като GitHub покаже адреса на сайта:

1. отвори **Firebase → Authentication → Settings → Authorized domains**;
2. добави домейна си, например `ivanboyanov.github.io` — без `https://` и без пътя след домейна.

## Локално тестване

Не отваряй `index.html` директно с `file://`, защото приложението използва JavaScript modules. В папката на проекта стартирай:

```bash
python -m http.server 8000
```

После отвори:

```text
http://localhost:8000
```

## Данни във Firestore

- `users/{uid}` — име, прогрес, дневни карти, статистика и до три лични списъка;
- `admins/{uid}` — ръчно зададена администраторска роля;
- `verbs/{verbId}` — глаголи, добавени през администраторския панел;
- `publicLists/{listId}` — публични списъци.

Вградените 331 глагола и петте начални списъка са в `js/verbs.js`, затова гост режимът работи и преди настройването на Firebase.
